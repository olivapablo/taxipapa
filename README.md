# 🚕 Taxímetro — PWA para Taxistas

Calculadora de tarifa con descuento del 20%. Ingresás el monto de la tickeadora y te muestra al instante cuánto cobrarle al pasajero.

---

## 📱 Cómo instalarla en el celular (Android)

1. Subí estos archivos a un repositorio de GitHub.
2. Habilitá **GitHub Pages**:
   - Ir a `Settings` → `Pages`
   - En "Branch" elegir `main` y carpeta `/ (root)`
   - Guardar
3. GitHub te da una URL tipo: `https://tu-usuario.github.io/tu-repo/`
4. Abrí esa URL en el navegador del celular (Chrome).
5. Tocá el menú (⋮) → **"Agregar a pantalla de inicio"**.
6. ¡Listo! Ya tenés el ícono en el escritorio como una app.

---

## 📱 En iPhone (iOS)

1. Abrí la URL en **Safari**.
2. Tocá el botón de compartir (□↑) → **"Agregar a pantalla de inicio"**.

---

## ⚙️ ¿Cómo funciona?

- Ingresás el monto que marca la tickeadora.
- El app calcula automáticamente el **20% de descuento**.
- Muestra el monto final a cobrarle al pasajero.
- Funciona **sin internet** una vez instalada (modo offline).
